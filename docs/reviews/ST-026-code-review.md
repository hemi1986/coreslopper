## Resolutions

| # | Resolution | Where |
|---|---|---|
| 1 | **fixed** – the import copies through `copyByContent(..., { stage: true })`, writes the entry, then commits the copies; a failed entry write discards the staging, a failed commit restores the entry (or removes a new one) and discards. `idTaken` ignores dot files, so a crash that leaves only `.incoming-*` no longer poisons the folder. | `set-library.ts:243-308,35-44` |
| 2 | **fixed** – references appended from a file the entry already holds are tracked in `refAdds` and deduped into `changes` with the new files and plates, so the entry is written and the history records them; test `adds a reference whose image the entry already holds`. | `set-library.ts:261-269,296`; `tests/set-library.test.ts` |
| 3 | **fixed** – `exists` is `resolve`-prefix plus `statSync(..., { throwIfNoEntry: false })?.isFile()`; a folder or FIFO named as a set file is reported missing, not fed to `fileHash`; test `treats a folder named as a set file as missing`. | `set-library.ts:231-232`; `tests/set-library.test.ts` |
| 4 | **fixed** – a same-id plate without a `file` gains the incoming one (and a missing plate prompt is filled), recorded as `plate:<id>`, instead of becoming `<plate>-<slug>`; test `fills the image of a plate the entry holds without one`. | `set-library.ts:270-294`; `tests/set-library.test.ts` |
| 5 | **fixed** – `--into` without `--id` is refused ("--into names one entry; name the set with --id as well"), so several sets can never be merged into one entry by accident; asserted in `puts a set into the entry the user names`. | `set-library.ts:222` |
| 6 | **fixed** – a set that names only missing files returns a skipped result with its `missing` list (`skipped: true`, no `id`), which the CLI prints; tests `skips a set without files …` and `refuses a set file outside the production`. | `set-library.ts:170-178,237-239`; `index.ts:931-940` |
| 7 | **fixed** – the guarded folder scan became `entryFileHashes` (`library-entry.ts`), used by `copyByContent` and `matchSetEntry`: dot files skipped, a non-file refused, one scan instead of two. | `library-entry.ts:116-129,145`; `set-library.ts:322-326` |
| 8 | **decided, question to the developer** – the numeric suffix stays (`numbered` reserves room so a long id can no longer cut the counter away, which also removes the loop); recording `<plate>-<slug>-<n>` in the invariant (and the character import's drop, which breaks the same invariant) is the user's call → `OPEN_QUESTIONS.md`. | `set-library.ts:192-203` |
| 9 | **decided** – every import into an existing entry writes a history row, with `added: []` when it brought nothing (invariant "every later import is recorded", EVT-LibrarySetExtended "one history row"); test `records every later import, even one that brings nothing new`. | `set-library.ts:297`; `tests/set-library.test.ts` |
