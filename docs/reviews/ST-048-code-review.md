## The worker's points

1. **Schema**: backward compatible (row 11). Old upload data and old manifests parse unchanged. An older runtime
   strips the new keys.
2. **Re-fixtured tests**: still check their scenarios. ST-044's scenario says "an episode whose first Short has the
   story text", and a 200 s vertical episode is an episode with Shorts and a story. ST-045's "an episode of 150
   seconds with a 9:16 render" is now a horizontal 150 s episode with a 9:16 derivative, which is exactly the main
   video that gets its Reel. "NEUE FOLGE" on a 200 s episode still composes the 16:9 post that it inspects. No other
   test uses the bare `episodeFixture()` apart from `release-shape.test.ts`, which overrides master and duration
   itself.
3. **Board**: ST-052 owns the shape line and the tabs, but the missing TikTok/Reel posts and the phantom story card
   are not in it (row 4).
4. **Publish**: no duplicate upload of the same file, but a leftover Short is uploaded, and the one video reaches
   TikTok only through `main.platforms` (row 2).
