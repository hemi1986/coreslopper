**fix blockers first** — one blocker and one major; the rest are judgement calls, and #12/#13 need a decision rather than a change.
Most important: `set add-file` copies the image before writing the entry and never rolls back, so a failed or interrupted write leaves a file in the set's folder that `set.yaml` does not name (reproducible with an `_`-named source, which also surfaces a raw `ZodError`).
