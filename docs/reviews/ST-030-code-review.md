Verdict: **fix blockers first** — 1 blocker, 0 majors, 3 minors, 3 questions. The two scenarios, the seam, the
language and the domain IDs are sound, but the blocker can break the aggregate invariant the command exists to restore.
Most important: writing the entry before deleting the file leaves a plain, unnamed file after a crash that `set remove` itself refuses to touch — stage the deletion as the add path stages its copies.
