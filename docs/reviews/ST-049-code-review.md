| 1 | blocker | merge-blocker: rule-bypass | packages/cli/src/release-qa.ts:160-177 (with release-files.ts:11,65) | Release QA runs `shortProblems` on every manifest entry of kind `short`. This is the worker's known gap, and it does break the story. `release` places a file with a 180 s limit, and QA rejects that same file against 60 s. That is the inconsistency the invariant rules out. Add a `releaseChecks` test with a 150 s vertical version. |
