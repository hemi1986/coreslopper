Checked and fine:
- Every non-GET route passes `trustedWrite` (loopback Host, Origin, `content-type: application/json`), and the 64 KB body limit applies.
- The slug goes through `slugOf` (`SLUG`) before any `join`. Character ids are checked before `entryDir` (`checkId`), so there is no path traversal.
- The idea is limited to 2000 characters and the setting by `optionalText`. Every refusal (idea, slug, character, budget, providers) happens before the folder exists.
- The page renders names and ids as text nodes (`el`), never as HTML. `setup` is completed through `finishSetup` → `setStageDone` + `saveState` (ADR 0037).
- The pitch keeps the user's words (ADR 0051). The tests sit at the board HTTP API seam from the seam catalog, carry the four exact scenario titles, and each checks its "Then". `check-language.ts` passes, and `tests/meme-wizard.test.ts` runs 8 of 8 green.

Verdict: ready to merge
Most important finding: #1. The wizard offers library characters whose ids contain an underscore, and then refuses them, because `characterIds` uses the project slug pattern instead of the library's id check.

## Resolution (main session, 2026-11-22)

- #1 fixed: `characterIds` no longer applies the slug pattern; `loadLibraryCharacter` checks each id with the library's rule. Test with `office_robot`.
- #2 fixed: `lipsyncProvider` is `unknown` and checked with `choice(...)`; an unknown value is a 400 before any folder exists. Test added.
- #3 fixed: `createProject` claims the folder with a plain `mkdir` (EEXIST → refused) and copies the template with `force: false`. Test: two creates of one slug at once.
- #4 fixed: the default budget is `max(10 USD, configured minimum)`. Test added.
- #5 partly: `--kind meme` refuses `--series`/`--episode`; `--brand` stays ignored (a meme has no brand kit in its template). The `--distribution` fix has no test: the repository has no harness that runs a commander command, and the option is declared exactly like `init`'s.
- #6 fixed: `finishSetup` needs a line in `pitch.md` that is not a heading. Test added.
- #7 skipped: `next` is part of the route's answer for API callers; the page builds the same command itself.
- #8, #9 skipped: sharing the wizard forms' setup and moving `createMeme` out of `board-wizard.ts` are refactors beyond this story; the music-video and episode commands live there the same way.
