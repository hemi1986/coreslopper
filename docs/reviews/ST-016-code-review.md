## Checked and fine

- The three scenarios have tests with the exact titles and each checks its "Then": the release has no `errors`, QA has no FAIL, and `Release sounds` is TODO with the sound id for scenarios 1 and 3 and PASS for scenario 2. The unit test for `soundLicenceTodos` uses literal expectations (including the missing entry, `cc-by-sa` with a credit, `own`, "public domain, no attribution required").
- The rule lives where the conventions put it: `soundLicenceTodos`, `licenceNeedsCredit`, `memeDescription` are pure functions in `packages/core/src/release.ts`; the CLI only reads files. `buildRelease` pushes them into `todos` (never `errors`), the manifest and `README.md`; `releaseChecks` reports TODO, never FAIL; the board's TODOs come from the manifest, which the scenario 1 test asserts.
- The credit still reaches the folder and the board: `usedLibrarySounds` replaces `usedSoundCredits` without changing the credit list (deduplicated by id, sorted, empty credits dropped), and `release`, QA, `projectReleaseContext` and the autopilot's Instagram Reel all derive from the same helpers.
- A missing/unreadable sound entry is now a TODO in the release check and the manifest (`{ id }` → "its entry is missing"), closing ST-015 review S3 for the release path.
- `ST-015`'s blocker (#1) still holds: the meme branch of `platformTextProblems` checks the exact `memeCaption` the texts carry, credits included.
- `check-language.ts` passes; `npm run typecheck` is clean; `tests/publish.test.ts`, `tests/release-folder.test.ts` and `tests/release-autopilot.test.ts` pass (97 tests). Nothing new is logged that is not public posting text; no new route or write.
- The autopilot passes the workspace root into `publish` (`workspaceRootOf`), so the tested path is the production path there; `PublishOptions.root` keeps the previous default.

Verdict: **fix blockers first**
Most important finding: **#1** – the upload posts the release caption only when the meme has at least one credit; for a meme with a cleared sound or no library sound, TikTok still gets the music-video text (title and hashtags, description dropped), which is the drift this story sets out to close.
